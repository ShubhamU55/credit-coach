## Test-first steps per task

1. Write the tests listed in Plan 4a for the task and run them: they fail because the module does not exist.
2. Write the smallest implementation that passes.
3. `pnpm --filter @credit-coach/mobile test`, then lint and typecheck, then commit.
4. Before the final report, `pnpm verify` from the repo root must exit 0.
