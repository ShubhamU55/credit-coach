**Goal:** a pure, rules-based score estimator for PRD §5.5 and §5.6. It returns a range plus reasons,
never one exact score. It also covers the six what-if scenarios and the hard-inquiry application guard.

**Spec:** PRD §4 (F1, F3, F6), §5.5, §5.6; `credit-domain` skill; `docs/design.md` §6.13–§6.15, §7.5

(seven weights totalling 100; guard N between 1 and 6).

**Owned files:** `packages/engine/src/{predictor,whatif,guard}*.ts` and their tests, append-only
lines in `packages/engine/src/index.ts`, this plan, the run ledger and journal 005.

## Model (decided up front so the tests can pin it)

- **Subscores:** each of the seven factors maps to a value in 0–1 through a monotone piecewise-linear
  curve, so every factor moves the estimate only in its documented direction.
- **Model score:** `M = 300 + 600 × Σ wᵢsᵢ / Σ wᵢ`. The weights are normalised, so an admin total that
  isn't exactly 100 still works.
- **With an anchor:** `center = anchor + modelShare × (M − anchor)`, rounded. The half-width is
  `round(baseHalfWidth + widenPerDay × daysSinceAnchor)`, capped at `maxHalfWidth`. The window
  slides inside 300–900 instead of clipping, so its width never collapses.
- **Without an anchor:** the 50-point bucket containing `M` (for example 700–749), with
  `isRoughBand: true`.
- **Reasons:** each factor is compared with a documented reference profile. The top three by
  weighted gap are returned, each with up, down or flat and the factor's own numbers. What-ifs
  compare the before and after states instead.
- **Calibration:** the defaults are calibrated to the Aarav fixture: 708–736 now, 724–752 with the
  plan, and 731–759 with the 10% switch on.
