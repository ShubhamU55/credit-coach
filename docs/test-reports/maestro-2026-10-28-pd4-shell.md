## Windows MAX_PATH fix for the native build (needed again for PD-15)

With the new native modules (react-native-gesture-handler, screens, safe-area-context) ninja fails even from a short checkout root (C:\p\t3), because CMake mirrors the full source path under `android/app/.cxx/<cfg>/<hash>/x86_64`:
`ninja: error: mkdir(rngesturehandler_codegen_autolinked_build/CMakeFiles/.../C_/p/t3/node_modules/react-native-gesture-handler/shared/...): No such file or directory`.
Fix (throwaway worktree only; android/ is generated by prebuild and never committed): after `expo prebuild`, add to the `android { }` block of the generated `android/app/build.gradle`:

    externalNativeBuild { cmake { buildStagingDirectory "C:/b/t3" } }

Then build as above. The AGP version accepted it, so no init script was needed. Delete C:\b\t3 afterwards.
