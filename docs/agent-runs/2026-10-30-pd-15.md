# PD-15 hardening

## What changed (commit `0db3192`)

- `apps/mobile/app.json` (android): `allowBackup: false` and `blockedPermissions` for `READ_EXTERNAL_STORAGE`, `WRITE_EXTERNAL_STORAGE` and `SYSTEM_ALERT_WINDOW`. Both keys are in the SDK 58 schema (`@expo/config-types` 58.0.3: `android.allowBackup`, `android.blockedPermissions`), and `npx expo config --type public` resolves them.
- `apps/mobile/src/demo/seed.ts`: `parseSeed` now checks `panMasked` against `^[A-Z]{2}X{5}\d{2}[A-Z]$` and `mobileMasked` against `^\+91 \d{2}X{5}\d{3}$`, the same shapes as the CHECK constraints in `supabase/migrations/20261028100000_core_tables.sql`. The error names the path and never echoes the value.
- Tests were written RED first (a full PAN `ABCDE1234F` and an unmasked mobile are rejected, and neither value appears in the message); the real `aarav.json` still parses.
