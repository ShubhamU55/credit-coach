## What was built

- `packages/engine/src/explain.ts`: `buildTemplateExplanation(plan, cards)` (deterministic text; only plan numbers, run through `formatINR`, `formatPercent`, `formatShortDate`) and `buildExplainPayload(plan, cards, { today, rules })` (the strict JSON for the function: numbers, ISO dates and reason codes, no free text). Exported from `index.ts` with types.
- `apps/mobile/src/explain/client.ts`: `fetchExplanation` posts the payload to `<EXPO_PUBLIC_SUPABASE_URL>/functions/v1/explain` with the public anon key. It never throws. Missing config, timeout (3000 ms), rejected fetch, non-2xx, bad JSON, wrong shape, empty or over-long text all return the template with `source: 'template'`.
- `apps/mobile/src/explain/useExplanation.ts`: `useExplanation(plan, cards, { today, rules }, options?)` returns `{ text, aiWritten, loading }`. The template is on screen on the first render; AI text replaces it only on a valid answer for the current plan (a stale answer for an older plan is ignored).

## Rulings

- Ruling: define the request/response contract myself - PD-5's `explain` function is not on main yet - request = `ExplainPayload` (`packages/engine/src/explain.ts`), response = `{ "text": string, "source": "ai" | "template" }` - cost if wrong: PD-5 adjusts to the payload type, or I change one parser function.
- Ruling: the hook returns `aiWritten` instead of a label string - the kit's `AIExplanation` already owns the two labels (design.md 6.16) - cost if wrong: none, one prop.
- Ruling: a `source: "template"` answer from the function is shown as template (no AI label) - the label must never claim AI for template text.
- Ruling: no number-consistency check on AI text in this ticket - the formats (Indian grouping, "22 Oct") make a safe check non-trivial and a false positive only costs the template - cost if wrong: an AI sentence could word a number differently; the function's own validation (PD-5) is the first line.

## One-line integration for the Plan screen (PD-9)

```tsx
const e = useExplanation(plan, cards, { today: DEMO_TODAY, rules }); // rules: { thresholdPct, aimFor10 }
<AIExplanation text={e.text} aiWritten={e.aiWritten} />;
```

`cards` is any `{ id, name }[]` (the `DemoCard[]` fits). Set `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_ANON_KEY` in `.env.local` for the live call; absent means template only.
